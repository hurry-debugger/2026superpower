# 工程架构与代码边界

## 1. 当前事实

以下结论来自 2026-10-26 对当前 `.ioc`、`Core/` 和 Keil 工程的静态读取，不是硬件运行记录。

- 芯片配置为 STM32G474CETx，生成代码使用 STM32G4 HAL / CMSIS。
- Keil 工程记录 ARMCC 5.06 update 6（build 750），当前未切换编译器。
- `main()` 依次调用 `HAL_Init()`、`SystemClock_Config()`，初始化 GPIO、DMA、HRTIM1、ADC1、ADC2。
- 随后分别校准 ADC1、ADC2，再调用两次 `HAL_ADC_Start_DMA()`；四次调用失败均进入
  `Error_Handler()`，成功后才调用现有 HRTIM 主计数器、A/B 定时器及输出启动函数；主循环为空。
- ADC1 循环 DMA 缓冲区 `adc1_raw[4]` 按通道 1、3、5、12 更新，ADC2 缓冲区
  `adc2_raw[1]` 对应通道 2；仅供观察原始计数，不保证多通道一致快照。
- 当前配置为 Timer A CMP3 → TRG1 → ADC1、Timer B CMP3 → TRG3 → ADC2；
  两个 DMA 通道均已有生成的中断入口。代码启动链路不等同于上板采样验证或物理量换算。
- 当前 `User/` 只有目录说明，未加入功率控制、协议、保护状态机或调度器实现。
- `references/` 中旧工程的模块、时序和算法不属于当前固件的已实现能力。

```text
复位 / 启动文件
    ↓
HAL 与系统时钟初始化
    ↓
GPIO / DMA / HRTIM1 / ADC1 / ADC2 初始化
    ↓
ADC1 / ADC2 单端校准及 DMA 启动，等待外部触发
    ↓
调用 HRTIM 计数器及输出启动函数
    ↓
空主循环
```

## 2. 文件归属

| 目录或文件 | 归属 | 操作边界 |
| --- | --- | --- |
| `.ioc` | CubeMX 配置源 | 禁止直接编辑；变更只能通过获批的 CubeMX 操作 |
| `Core/` | CubeMX 生成代码 | 仅获批 USER CODE 内部可编辑，区域外及标记行保持原样 |
| `Drivers/` | HAL / CMSIS 厂商代码 | 不直接改写或套用项目格式 |
| `MDK-ARM/` | 工程配置、生成启动/RTE、用户调试配置和产物 | 本轮不改；后续按来源与授权处理 |
| `User/` | 自维护固件 | 获批后编写，遵守项目代码规范 |
| `templates/` | 可复用示例 | 不参与 Keil 构建，不代表运行功能 |
| `docs/`、`tools/` | 自维护文档和检查工具 | 改动同样需要事先批准 |
| `references/` | 本地参考资料 | 只读参考，不自动复制、接入或改写 |

生成身份优先于目录名。生成文件移到 `User/` 后仍只允许修改获批的 USER CODE 内部；
检查工具对常见生成标记的识别只是辅助，不能证明没有标记的文件就一定是自维护文件。

## 3. 未来自维护代码规划

下列分层尚未实现，本轮不创建业务目录、迁移源码或调整 Keil 分组。

| 规划目录 | 职责 | 依赖方向 |
| --- | --- | --- |
| `User/App/` | 应用状态、任务编排、保护策略、模块协作 | 使用 Bsp、Algorithm、Config 的接口 |
| `User/Bsp/` | 板级采样、输出、外设访问和收发封装 | 可使用 HAL、Algorithm 和 Config，不依赖 App |
| `User/Algorithm/` | PID、滤波、限幅等纯算法 | 不依赖 HAL、App 或 Bsp |
| `User/Config/` | 板级与业务参数、单位和来源 | 不包含运行流程或驱动副作用 |

协议业务归 App，字节收发归 Bsp；将来需要拆出专门模块时再提出具体变更。
避免跨层直接修改全局状态。共享状态、更新者、读取者、更新频率和同步方式必须明确。
中断中允许执行的函数及其最大执行时间应在实现和测试时说明，不能沿用旧工程数字作为事实。

## 4. 后续接入要求

先提出用户模块的接口、启动顺序、回调/中断上下文和构建接入方式，再取得用户批准。
初始化调用和回调可放入获批的 USER CODE 区域内部，区域外内容及标记行必须保持原样；
不得自行创建 USER CODE 标记、使用重复中断符号或覆盖生成物。
本轮仅在 `main.c` 的 PV 和 2 区域添加缓冲区及启动代码，不新增回调或调整构建配置。
